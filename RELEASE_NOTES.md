## 🌐 GitHub Pages Quick Deployment

1. Create a public repository named `portfolio` on GitHub.
2. Initialize git and push workspace files:
   ```bash
   git init
   git add .
   git commit -m "Production Release v1.0.0"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git push -u origin main
   ```
3. Go to **Settings** -> **Pages** -> Select `main` branch -> **Save**.
4. Access live site at: `https://YOUR_USERNAME.github.io/portfolio/`
